1.	Analogy that helps me visualize the terminology of accessing a website; send a package through a delivery system:
DNS = address book for computer readable format
BGP = navigation/routing - Which sequence of transportation networks should carry the package toward that address
TCP = reliable delivery procedure - Did the packages arrive, in what order, and should we resend missing ones
TLS = sealed packaging - outsiders can still see where the package is being transported, but have much less visibility into its contents
